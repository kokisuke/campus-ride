# 🚗 Campus Mobility Project  
**大学×企業×学生でつくる新しいモビリティのかたち**

---

## 🌐 プロジェクト概要
**Campus Mobility Project** は、名古屋市立大学を中心に、大学生の移動を支援しながら  
地域企業との連携を促進する新しい産学連携モデルです。

- 大学がリースした車両を学生が利用（無料）
- スポンサー企業の広告を車体・バスに掲載
- 自動運転バスでキャンパス間を接続
- 広告効果と社会貢献を両立する仕組み

---

## 🏫 対象キャンパス
- 滝子キャンパス（人文・経済学部など）  
- 桜山キャンパス（医学・看護学部）  
- 田辺通キャンパス（芸術工学部）  
- 北千種キャンパス（データサイエンス学部）
