# 🚗 Campus Mobility Project  
**大学×企業でつくる、新しいモビリティのかたち**

---

## 🌐 プロジェクト概要
**Campus Mobility Project** は、名古屋市立大学の学生が中心となって進める、次世代の移動サービスプロジェクトです。学生の移動を支援するとともに、企業にとっての新たな広告機会を提供する革新的な取り組みです。

### 🎯 プロジェクトの特徴
- **学生の移動支援**: 大学と学生と企業の連携による無料カーシェアサービス
- **企業広告機会**: スポンサー企業による効果的な広告展開
- **最先端技術**: 新しいモビリティのかたちの創造に挑戦
- **産学連携**: 大学×企業の協力による持続可能なビジネスモデル

## 🏫 名古屋市立大学について
**名古屋市立大学**は1950年に設立された公立大学で、「知と文化の拠点として、豊かな人間性と創造性に富む人材の育成と、独創的な学術研究を通じて、人類の福祉と世界平和に貢献する」ことを理念としています。

- **経済学部** - 経済学科
- **人文社会学部** - 心理教育学科、現代社会学科、国際文化学科
- **芸術工学部** - 情報環境デザイン学科、産業イノベーションデザイン学科、建築都市デザイン学科

## ✨ サイトの主要機能

### 🏠 **ホームページ (`index.html`)**
- **ヒーローセクション**: 薄い青グラデーション背景でプロジェクトビジョン表示
- **プロジェクト概要**: 学生移動支援と企業広告機会の説明
- **在校生向けセクション**: カーシェア・自動運転バス利用案内、利用詳細ページへの誘導
- **企業向けセクション**: 広告機会とスポンサーシップ案内、詳細ページへの誘導
- **名古屋市立大学紹介**: 大学概要、7学部詳細、公式サイトリンクボタン
- **レスポンシブナビゲーション**: 全ページ統一デザインのヘッダー

### 📖 **プロジェクト内容ページ (`about.html`)**
- **プロジェクトコンセプト**: 4つの核心要素をカード形式で表示
- **電気自動運転バス**: 実車画像表示エリア、詳細スペック、特徴ハイライト
- **サービス仕組み**: 4ステップフローでサービス流れを図解（デスクトップ表示で中央揃え最適化）
- **サービス特徴**: 学生向け・企業向けメリットを2カラムで表示
- **導入技術・システム**: AI自動運転、専用アプリ、K-MaCS評価システム、デジタルサイネージ
- **K-MaCSの活用**: 運転技能評価システムの詳細説明、4つの主要機能、外部サイトリンクボタン
- **期待効果**: 教育面・地域貢献・技術革新・SDGsの4つの観点から説明

### 🎓 **在学生向けページ (`student.html`)**
- **予約アプリ使い方**: 4ステップガイド（ダウンロード→検索→予約→受取）
- **利用ルール**: 基本ルール、禁止事項、事故対応、利用マナーを詳細表示
- **ランク優遇制**: プラチナ〜ブロンズの4段階ランク制度、評価項目、優遇内容
- **予約サイトアクセス**: 専用予約システムへのリンクボタン

### 🏢 **企業向けページ (`sponsor.html`)**
- **スポンサーシップメリット**: 露出効果、若年層アプローチ、CSR、産学連携
- **広告掲載場所・媒体**: 4つのカードを1行配置（学生・職員利用車両、キャンパス間自動運転バス、公式サイト、予約webアプリ）
- **運行ルート**: 4キャンパス間主要ルート、利用統計データ
- **スポンサーパッケージ**: プレミアム（200万円〜）、スタンダード（130万円〜）、ベーシック（60万円〜）
- **お問い合わせフォーム**: 企業情報入力、パッケージ選択、詳細相談

## 🚀 セットアップ・使用方法

### ローカル環境での実行
```bash
# リポジトリをクローン
git clone [repository-url]

# プロジェクトディレクトリに移動
cd campus-ride

# ローカルサーバーを起動（例: Live Server、Python HTTP Server）
python3 -m http.server 8000
# または
npx live-server
```

### GitHub Pagesでの公開
1. GitHubリポジトリにプッシュ
2. Settings → Pages → Source: Deploy from a branch
3. Branch: main → Save
4. 数分後に `https://[username].github.io/campus-ride/` でアクセス可能
